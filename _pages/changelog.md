### `Initial Release`

# **Version 1.0**

Pocket API Client は、個人開発者のためのモバイルAPIテストツールです。Postmanライクな操作感で、REST APIのリクエスト送信・レスポンス確認・認証設定をiPhoneからいつでもどこでも手軽に行えます。コレクション管理や環境変数にも対応し、開発中のAPIデバッグをスムーズにサポートします。

#### What's New

- GET / POST / PUT / DELETE など主要HTTPメソッドに対応
- ヘッダー・クエリパラメータ・リクエストボディの詳細設定
- Bearer Token・Basic認証・API Keyなど主要認証方式をサポート
- リクエストのコレクション保存・管理機能
- 開発・ステージング・本番環境の切り替えに対応した環境変数機能
- 過去リクエストの自動履歴保存機能
- 日本語・英語をはじめとする多言語対応
